# Dashboard Ozon

Прибыль магазина на Ozon каждое утро: сколько заработано чистыми за вчера, неделю, месяц, куда ушли деньги, сколько остаётся с одной штуки. Плюс реальный факт по начислениям Ozon за месяц.

Работает целиком в ваших бесплатных аккаунтах GitHub и Cloudflare: ничего не ставится на компьютер, ключи и цифры видите только вы.

**Как установить — [INSTRUKCIYA.md](INSTRUKCIYA.md).** Около часа, всё в браузере, на Mac и Windows одинаково.

## Как считается

- **Прибыль дня** — по заказам дня: заказы × процент выкупа × цена дня, минус комиссия Ozon, логистика и услуги, налог, закупка, реклама, общие расходы Ozon и ваши расходы (зарплаты и т. п.). Комиссия, логистика и выкуп берутся из ваших реальных данных Ozon за последние 7 дней, а не из справочников.
- **Факт** — по начислениям Ozon за месяц, как в кабинете: Финансы → Начисления.
- **Налог** — по вашим настройкам: УСН «доходы» или «доходы минус расходы», НДС внутри цены. База — продажи из отчёта Ozon, доплата банка Ozon и баллы, пришедшие деньгами. Баллы, которыми Ozon погасил свою комиссию, в доход не идут (письмо ФНС от 02.09.2026 № СД-35-3/11693@). Сверьте с бухгалтером.
- Модель FBO (склады Ozon).

## Что где лежит

- `sbor/` — сбор данных из Ozon и расчёт (Python, запускается в GitHub Actions);
- `sayt/` — страница;
- `worker/` — вход по паролю и сохранение настроек (Cloudflare Workers);
- `nastroyki.json` — ваши настройки (правятся на странице «Настройки»);
- `dannye/` — собранная история.
